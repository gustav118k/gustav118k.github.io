4. Datenverarbeitung auf der Seite „Wann Mensa heute?"

4.1 Uhrzeitvorschlag (KI-Antwort)

Daten, die verarbeitet werden: Wenn Sie eine Uhrzeit eingeben und auf „Andere Uhrzeit vorschlagen" klicken, wird diese Eingabe an den Backend-Service mensa-llm-backend.vercel.app übermittelt.

Zweck: Generierung einer KI-gestützten Antwort mittels Google Gemini 2.5 Flash API.

Empfänger: Der Backend-Service (gehostet auf Vercel) leitet Ihre Eingabe an die Google Gemini API weiter. Google verarbeitet die Daten nach Maßgabe seiner Datenschutzerklärung.

Speicherung: Ihre Eingaben werden nicht auf dieser Website gespeichert. Die Verarbeitung erfolgt in Echtzeit; die Antwort wird danach verworfen.

Rechtliche Grundlage: Verarbeitung auf Basis Ihrer ausdrücklichen Einwilligung (Sie klicken aktiv den Button).

4.2 Zufällig generierte Gerichte

Das Feature „Was gibt es heute?" generiert zufällig ein Gericht aus einer festen Liste. Es werden keine Daten übermittelt oder verarbeitet; alles läuft lokal in Ihrem Browser.

4.3 Datenweitergabe an Dritte

Durch Nutzung des „Uhrzeitvorschlag"-Features akzeptieren Sie, dass Ihre Eingabe an Google Gemini API weitergeleitet wird. Eine darüber hinausgehende Weitergabe findet nicht statt.
